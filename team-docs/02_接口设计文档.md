## 一、接口总则

### 1.1 分层调用规则

```
main.py  →  desktop_pet.py  →  core/*  →  config.py
                              ↑
                          ui/widgets/*
```

- **上层可调下层**，下层不可调上层（禁止 core 调 ui）
- **同层可互相调**，但须通过本文档定义的接口
- **config.py 是全局只读配置源**，任何层都可读，但只有 ui/settings_dialog.py 通过 save_config 写入

### 1.2 回调约定

AI 后端和语音管线大量使用回调函数传递状态：

```python
# 标准回调签名
on_delta: Callable[[str], None]        # 流式增量文本
on_status: Callable[[str], None]       # 状态文本（显示给用户）
on_tool_event: Callable[[dict], None]  # 工具调用事件
on_approval: Callable[[dict], str]     # 审批请求，返回 "approve"/"deny"
```

## 二、核心接口定义

### 2.1 路由层接口（backend_router.py）

这是整个 AI 对话的统一入口，所有对话请求都经此分发。

```python
def route_and_send(
    *,
    config: dict,                        # 来自 storage.load_config()
    input_text: str,                     # 用户输入
    soul_md: str,                        # 角色人设（来自 agent_client._load_soul_md）
    conversation_history: list[dict] | None = None,  # 对话历史
    memories: list[dict] | None = None,  # 本地记忆
    on_delta: Callable[[str], None] = lambda t: None,
    on_status: Callable[[str], None] = lambda t: None,
    on_tool_event: Callable[[dict], None] = lambda e: None,
    on_approval: Callable[[dict], str] = lambda p: "deny",
    system_role: str = "user",           # "user" | "companion"（companion 强制走 chat）
    skip_history: bool = False,
    inject_system_prompt: str | None = None,
) -> tuple[str, str]:
    """
    返回 (reply_text, backend_name)。
    backend_name ∈ {"local", "hermes", "harness", "deepseek", "codex"}
    """
```

**调用方**：desktop_pet.py 的 AgentTask.run()、core/voice_call.py
**被调方**：agent_client / deepseek_client / codex_client / harness_bridge / hermes_launcher

### 2.5 IPC 接口（ipc_command.py）

```python
# overlay 进程 ↔ renderer 进程的命令序列化
def serialize_command(**payload: Any) -> tuple[str, dict]
    """将命令序列化为 (json_str, metadata)，通过 mp.Pipe 发送"""

def apply_command_js(payload: dict) -> str
    """将命令转为 JS 可执行的 HTML 片段（供 renderer webview 执行）"""
```

**命令类型**（payload 中的 key）：
| 命令 | 方向 | 说明 |
|------|------|------|
| `emotion` | overlay→renderer | 更新 Live2D 表情 |
| `motion` | overlay→renderer | 播放 Live2D 动作（头部/肢体，如 hands_on_hips 叉腰、arms_crossed 抱胸） |
| `mouth` | overlay→renderer | 口型强度 0.0-1.0（音量驱动，经 setMouth 平滑插值） |
| `speaking` | overlay→renderer | 控制口型动画 |
| `text` | overlay→renderer | 更新对话文本 |
| `delta` | overlay→renderer | 流式追加文本 |

def build_snapshot() -> ContextSnapshot

    idle_seconds: int
    clipboard_text: str
    screen_b64: str
    timestamp: float

# expression.py — 表现层解码器（回复 → Live2D 表情/动作指令）
@dataclass
class ParsedExpression:
    emotion: str   # neutral|blush|angry|smile|sad|thinking
    motion: str    # neutral|smile|blush|angry|sad|thinking|hands_on_hips|arms_crossed|facepalm|shrug|chin_rest
    mouth: float   # 口型强度 0-1（规则解析恒 0）

def decide_expression(reply: str, *, ollama: dict | None) -> ParsedExpression
    """综合判定：有 ollama 配置 → 先小模型，失败/空 motion 回退 parse_expression"""

# controller.py — CompanionController.handle_signal 新增回调
# on_expression: Callable[[ParsedExpression], None]  # 回复生成后、on_finished 前回调

### 2.9 配置接口（config.py）

config.py 是全局只读配置源，定义以下常量（所有模块通过 `from config import XXX` 使用）：

| 常量名 | 类型 | 说明 |
|--------|------|------|
| `RESOURCES_DIR` | Path | 资源根目录 |
| `HERMES_DEFAULTS` | dict | Hermes 后端默认配置 |
| `OPENCLAW_DEFAULTS` | dict | OpenClaw CUA 默认配置 |
| `AGENT_ROUTER_DEFAULTS` | dict | Agent 路由默认配置 |
| `HARNESS_DEFAULTS` | dict | Harness 完整配置默认值 |
| `COMPANION_DEFAULTS` | dict | Companion 主动问候默认配置 |
| `PHONE_DEFAULTS` | dict | 电话模式默认配置 |
| `GPT_SOVITS_DEFAULTS` | dict | GPT-SoVITS 运行模式配置 |
| `TTS_PROVIDER_DEFAULT` | str | 默认 TTS 提供商 |
| `VAD_PARAMS` | dict | VAD 参数 |
| `KURISU_PERSONALITY` | str | 红莉栖人设（fallback） |
| `KURISU_OUTPUT_FORMAT` | str | 输出格式指令 |
| `APPROVAL_POLICY` | str | 工具审批策略 |

| 函数 | 签名 | 说明 |
|------|------|------|
| `resources_path(relative_path: str) -> Path` | 把 `/xxx` 转为 resources/ 绝对路径 |
| `get_character_by_id(character_id: str) -> Character` | 按ID获取角色配置 |
| `get_random_greeting(character_id: str) -> str` | 随机问候语 |

## 四、接口变更流程

1. **提出方** 在本文档对应章节标注 `[拟变更]` 并描述新签名
2. **依赖方** 在 24h 内确认或提出修改意见

4. **禁止**：先改代码再补文档，或跨层直接调用未文档化接口
